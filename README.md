# CampusEvents

A JavaScript web application for browsing and filtering campus events by category.

## Features

- Loads event data from `events.json`.
- Displays events as cards.
- Filters events by category.
- Updates the event counter when filtering.
- Displays a message when no events match the selected category.
- Shows an error message if event loading fails.

## Technologies

- HTML
- CSS
- JavaScript ES modules
- Fetch API

## How to Run

Open the project using a local development server, such as the VS Code Live Server extension. Then open the page in your browser.
